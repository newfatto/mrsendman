# MrSendMan

**MrSendMan** — Django-сервис для управления email-рассылками: получатели, письма, рассылки, ручной запуск отправки, статистика попыток, роли пользователей и кеширование.

## Описание проекта

MrSendMan — учебный backend/web-проект на Django, реализующий сервис для подготовки и управления email-рассылками.

Пользователь может создавать базу получателей, подготавливать письма, настраивать рассылки с периодом действия и запускать отправку вручную из интерфейса. Для каждой рассылки фиксируются попытки отправки писем, их статус и результат, что позволяет просматривать общую статистику и статистику по отдельным рассылкам.

Проект демонстрирует работу с классическим Django-приложением: моделями, формами, шаблонами, авторизацией, ролями, правами доступа, SMTP-отправкой, PostgreSQL, кешированием и настройкой проекта через переменные окружения.

## Основной функционал

### Рассылки

- Создание, просмотр, редактирование и удаление рассылок.
- Настройка периода действия рассылки.
- Выбор письма для отправки.
- Выбор списка получателей.
- Валидация дат:
  - дата старта не может быть в прошлом;
  - дата старта должна быть раньше даты окончания.
- Динамический статус рассылки:
  - создана;
  - запущена;
  - завершена.
- Ручной запуск рассылки из интерфейса.
- Создание попыток отправки по каждому получателю.

### Получатели

- Создание, просмотр, редактирование и удаление получателей.
- Хранение данных получателя:
  - email;
  - ФИО;
  - комментарий.
- Ограничение доступа: пользователь работает только со своими получателями.

### Письма

- Создание, просмотр, редактирование и удаление писем.
- Хранение темы и тела письма.
- Использование созданных писем в рассылках.
- Ограничение доступа: пользователь работает только со своими письмами.

### Пользователи и доступ

- Регистрация пользователей.
- Подтверждение email при регистрации.
- Авторизация и выход из аккаунта.
- Восстановление пароля.
- Разграничение прав доступа:
  - обычный пользователь управляет только своими получателями, письмами и рассылками;
  - менеджер может просматривать данные сервиса, блокировать пользователей и отключать рассылки.
- Кастомная команда для наполнения группы менеджеров:

```bash
python manage.py add_managers
```

### Статистика

- Сохранение попыток отправки писем.
- Фиксация результата попытки:
  - успешная отправка;
  - ошибка отправки.
- Просмотр итоговой статистики по попыткам.
- Просмотр статистики по каждой рассылке.
- Агрегация данных по успешным и неуспешным попыткам.

### Кеширование

- Серверное кеширование главной страницы через `cache_page`.
- Кеширование расчётов статистики пользователя через `cache.get` / `cache.set`.
- Клиентское кеширование публичных страниц через `Cache-Control`.
- Использование Redis как backend для кеширования.

## Архитектура проекта

Проект разделён на несколько логических зон:

- **Пользователи** — регистрация, подтверждение email, авторизация, восстановление пароля, роли.
- **Получатели** — база контактов пользователя для рассылок.
- **Письма** — шаблоны сообщений с темой и телом письма.
- **Рассылки** — период действия, выбранное письмо, список получателей и статус.
- **Попытки отправки** — фиксация результата отправки письма каждому получателю.
- **Статистика** — агрегированные данные по успешным и неуспешным попыткам.
- **Кеширование** — ускорение главной страницы и статистических расчётов.

## Установка и запуск локально

### 1. Клонировать репозиторий

```bash
git clone https://github.com/newfatto/mrsendman.git
cd mrsendman
```

### 2. Установить зависимости

```bash
poetry install
```

### 3. Создать файл `.env`

Создайте файл `.env` по примеру `.env.sample` и заполните переменные окружения.

Пример переменных:

```env
SECRET_KEY=your_secret_key
DEBUG=True

DB_NAME=your_db_name
DB_USER=your_db_user
DB_PASSWORD=your_db_password
DB_HOST=localhost
DB_PORT=5432

EMAIL_HOST=smtp.example.com
EMAIL_PORT=587
EMAIL_HOST_USER=your_email@example.com
EMAIL_HOST_PASSWORD=your_email_password
EMAIL_USE_TLS=True

CACHE_ENABLED=True
```

### 4. Применить миграции

```bash
poetry run python manage.py migrate
```

### 5. Создать суперпользователя

```bash
poetry run python manage.py createsuperuser
```

### 6. Запустить сервер

```bash
poetry run python manage.py runserver
```

После запуска проект будет доступен по адресу:

```text
http://127.0.0.1:8000/
```

## Работа с менеджерами

Для добавления пользователей в группу менеджеров используется кастомная команда:

```bash
poetry run python manage.py add_managers
```

Менеджер может:

- просматривать данные сервиса;
- блокировать пользователей;
- отключать рассылки.
