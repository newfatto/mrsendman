# MrSendMan — сервис управления email-рассылками (учебный проект)

Веб-приложение на Django для создания получателей, писем и рассылок, ручного запуска отправки и просмотра статистики по попыткам.

## Стек
- Python 3.13
- Django 6
- PostgreSQL
- HTML / Bootstrap 5
- Poetry (управление зависимостями)
- SMTP (отправка писем)
- Кеширование (Redis)

## Функциональность
### Рассылки
- CRUD рассылок (период отправки, выбор письма, список получателей)
- Валидации дат (start_time не в прошлом, start_time < end_time)
- Динамический статус рассылки (создана/запущена/завершена)
- Ручной запуск рассылки из интерфейса (создание попыток отправки по каждому получателю)

### Получатели и письма
- CRUD получателей (email, ФИО, комментарий)
- CRUD писем (тема и тело письма)

### Пользователи и доступ
- Регистрация с подтверждением email
- Логин/логаут, восстановление пароля
- Разграничение доступа:
  - пользователь управляет только своими сущностями
  - менеджер просматривает данные сервиса и может блокировать пользователей/отключать рассылки
- Для наполнения группы "Менеджеры" может быть использована кастомная команда:
    ``` bash
  python manage.py add_managers

### Статистика
- Итоговая статистика по попыткам (успех/ошибка)
- Статистика по каждой рассылке (агрегации по попыткам)

### Кеширование
- Серверное кеширование главной страницы (cache_page)
- Кеширование расчётов статистики по пользователю (cache.get/set)
- Клиентское кеширование через Cache-Control для публичных страниц

## Установка и запуск (локально)
1) Клонировать репозиторий
2) Установить зависимости:
   ```bash
   poetry install
3) Создать .env по примеру .env.sample и заполнить переменные (БД, почта, SECRET_KEY)
4) Применить миграции:
     ```bash
   poetry run python manage.py migrate
5) Запустить сервер::
     ```bash
   poetry run python manage.py runserver
